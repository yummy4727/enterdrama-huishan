# 回山试玩版（working title）

One line: 把入戏的正式剧本《回山》做成一段手机浏览器即点即玩的互动试玩 H5，玩到悬念处切断，把人导去官网——一份"能玩的买量广告"。

（EN TL;DR: A playable-demo H5 built from the 入戏 app's real script assets — play a crafted slice of the xianxia-romance script《回山》with voiceover and art, hit a cliffhanger cut, and get funneled to the official website. Ad slots are structural placeholders in this POC.)

## The Unique Kernel
游戏买量圈早就验证了 playable ad 是转化率最高的广告形态，但没人把"文字互动剧"做成试玩广告。这个项目的内核：**用真实剧本资产（TTS 配音 + 场景美术 + 分支剧情）把"下载这个 App"变成"先玩 3 分钟再说"**。它不是宣传片，是产品本体的一刀切片。

## Who It's For
在微信群/朋友圈点开一张剧情分享卡的人：言情/修仙小说读者、乙女向文字游戏玩家（女性向为主）。他们爱看故事，但对"下载一个陌生 App"极度警惕——今天他们刷小说推文短视频、读番茄小说。3 分钟无需登录的试玩，是他们愿意给陌生产品的最低信任门槛。

## The Core Loop
点开链接 → 无菜单无加载页，第一秒就是配音台词 + 场景图 → 读一段 → 做选择 → 剧情真的分岔 → 悬念刚拉起来就切断 → "结局在入戏"结算页 → 跳官网。
回来的理由：重玩换另一条分支看不同走向；把分享卡甩给朋友"你选哪个"。

## Inspiration & Identity
- 手感对标游戏 playable ad：即点即玩、第一秒必须有反馈、无任何注册摩擦
- 视觉沿用《回山》现成场景美术：修仙言情、古风水墨氛围
- 节奏对标小说推文的"黄金三章"逻辑：最短路径给到爽点，每次选择都有可感知的后果
- 具体切断幕次待 3-prd 读《回山》剧本 JSON 后钉死（原则：玩家做过 1-2 次选择、尝到分支后果、更大的钩子刚出现处切断）

## Why This Matters to the Learner
这是给入戏做的可复用增长资产：比赛结束后可以直接挂到官网/社群真实投放，验证"试玩 → 官网 → 下载"的漏斗。一份工作两份收益——比赛提交 + 真实导流工具。同时跑通一遍官方 skill pack 的完整流程。

## What "Working" Looks Like
手机浏览器（含微信内置浏览器）点开链接，无登录，30 秒内进入第一幕（配音 + 场景图 + 打字机台词）；完整走完：开场 → 2 个选择点（分支真实改变后续文本）→ 悬念切断 → 导流结算页（跳官网按钮可点）。页面含两处广告占位（底部 banner 位 + 结算页激励视频位）。
"oh, that's cool" 的一拍：点开第一秒就是出声的剧情，第一次按下选择键后下一幕真的不一样。

## The POC Boundary
- 单剧本《回山》一条精选试玩线（从正式剧本资产裁剪）
- 内容全预制：剧本 JSON + TTS 音频 + 场景美术，静态资产托管，无实时 LLM 调用
- 2 个选择点、1 个切断悬念点、1 个导流结算页（跳官网）
- 广告位占位演示：结构搭好、占位素材演示，不接真实广告网络
- 移动端 H5 优先；微信内置浏览器与手机浏览器可开；桌面可开不深度优化
- 纯前端 + 静态托管，无自建后端

## Later
- 多剧本模板化（其他剧本套同一播放器）
- 真实广告网络接入（结算页激励视频 / banner）
- 分享卡自生成（带玩家选择结果的个人化图卡）
- 埋点与转化数据统计
- 口令导流 / 深度链接直达入戏内对应剧本
- 桌面端深度适配

## Explicitly Cut
- **登录/账号体系** — 试玩即玩是转化的前提，登录会把漏斗打穿，POC 完全不需要
- **自建后端/API** — 内容与导流全是静态的，后端是纯多余复杂度
- **实时 AI 生成剧情** — 内容已预制；实时 LLM 徒增成本、延迟与不可控性（"Built with AI"体现在构建过程，不要求运行时）
- **剧情编辑器 / 多剧本接入** — 那是把 POC 做成产品，超出一届 hackathon 的体量
- **桌面端深度适配** — 传播与消费场景都在手机
