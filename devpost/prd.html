回山试玩版 · 产品定义

把入戏正式剧本《回山》的第一、二幕原样裁成 seq 1–368 的有声互动试玩，玩到"涂药定格"处切断，把人导去官网——一份能玩的买量广告。
Scope 说"分支真实改变后续文本"；现在钉死了是哪两处选择（seq 66 / 272）、选项原文是什么、切在哪一句。

核心旅程

一条主线 + 两次分支 + 一个切断。朱砂为玩家参与点。

分步细则

逐步翻看每一段的"画面 / 玩家 / 系统 / 验收"。

行为细则

点开各组看完整行为与验收标准。

有声播放器
  • 旁白逐句播 nar_*.mp3（切片内全量现成）；台词行播角色配音——构建期盘点现成资产，缺的只为这 368 步补生成，不许台词无声。
  • 打字机与配音同步；点击屏幕＝未完句立即完整、已完成则下一句；音频不打断。
  • BGM 按 music 步切换循环（bgm_daily → bgm_uneasy → 回 bgm_daily）；不播剧本文本外音效。
  • 背景随 background 步淡入淡出（本切片 4 张：shop_dusk / shop_night / store_night / courtyard_night）。
  • 轻触后 3 秒内第一句配音出声
  • 每句出现即有声；点按能跳句不卡死
  • 4 处背景切换与 music 步切换在正确节点发生
玩家选择（两处）
  • seq 66 / seq 272 各弹 4 选项：3 个剧本原文选项（逐字照抄，不缩写不润色）+ 1 个"（不答话）"（即剧本超时支，无倒计时）。
  • 选择后按钮收起、播对应分支、汇合后继续；选择记入结算页摘要。
  • 两处各出 4 枚按钮，文案与剧本正本逐字一致
  • 选 A 与选 B 后接下来的台词确实不同（对照两条路径各走一遍）
  • "（不答话）"走通剧本超时支（seq 67→89 / seq 273→299）
结算页（导流）
  • 自上而下：定格背景压暗 + 朱砂印"待续" → 悬念文案 → "你的选择"摘要 → CTA → 激励视频占位卡 → "重玩一次"。
  • 悬念文案初稿：主句"天亮之前，他得给个答案。"副句"可这段对话，停在了药膏擦上去的那一刻。"（agent 起草，待学习者批准）
  • 摘要两行：第一幕，你替江明说：「……」 / 第二幕，你替江明说：「……」；选沉默则显示"他没答话。"
  • CTA "去入戏 App 看结局" → 新窗口打开 https://www.enterdrama.cn/
  • document.title＝分享标题初稿："入戏·回山试玩｜天亮之前，他得选"（微信分享卡默认取页面标题，不接 JS-SDK）
  • 摘要与实际所选逐字一致（含沉默显示"他没答话。"）
  • CTA 在微信与手机浏览器中都能打开官网
  • "重玩一次"清空进度、回到轻触首屏
广告占位（假素材演示）
  • 底部 banner 位：自制古风修仙风假广告图 + "广告"角标；播放中常驻（结算页隐藏）。
  • 激励视频位：结算页假广告卡 → 点击演示完整结构：全屏假广告图 → 3 秒倒计时 → 出现关闭 → 返回结算页。
  • banner 播放全程可见（结算页除外）、带"广告"角标
  • 激励视频位可走完"点开→倒计时→关闭→回结算页"全流程
进度与重玩
  • localStorage 记当前 seq 路径位置 + 两个选择结果；关页重开直接恢复到断点台词（不询问）。
  • 无进度 → 从轻触首屏开始；结算页"重玩一次" → 清记录从头。
  • 播到任一处关页重开，接着上一句继续，已做选择不丢
  • 清空 localStorage 后从头开始

状态与边界

状态表现
首次使用手机浏览器禁自动出声 → 首屏＝第一幕背景铺满 + "轻触 开启剧情"印，点击后音频起。对 scope"无加载页"的最小调和：无菜单信息，只有一次必要点击。（构建期按微信实测校准）
断点恢复有进度→直接跳断点继续（选择结果一并还原）；无进度→从头。
音频缺失/慢台词照常打字机推进，配音静默降级，绝不阻塞或白屏。
资产加载失败背景缺失用暗色底 + 场景名淡字占位，流程不中断。
结算页是终点只能跳官网或重玩，无"继续阅读"。
微信内置浏览器可完整游玩；分享卡标题即页面 title；不接 JS-SDK。
桌面端居中竖屏画布可完整走通，不深适配。
内容边界只播正本 seq 1–368，剧本文字零改动；新增文字仅限界面 chrome + 结算页文案 + 分享标题（均已列初稿）。

已定的产品决定

玩家双角色全操纵
原版双人对局，H5 单人玩：江明、惠卿的选择都由玩家做。本切片两处选择都是江明的，摘要称"你替江明说"。
切断点＝第二幕末"她继续替他抹开。"（seq 368）
符合 scope 原则：2 次选择已做、分支后果已尝到、接脉大钩子已砸下，在最温柔处突然断掉。
开场约 64 步日常原样保留
日常铺垫是这剧本的根，黄金三章逻辑靠日常质感立信，不精简。
超时支做成"（不答话）"普通选项
保留剧本超时内容，不给玩家倒计时压力。
localStorage 断点续玩 ｜ 结算页带"你的选择"摘要 ｜ 假广告做像样的假图 ｜ 视觉古风拟物
均为学习者逐项拍板。
官网 https://www.enterdrama.cn/ ｜ 结算/分享文案由 agent 起草

不做与顺延

POC 外顺延
  • 第三幕起的全部剧情（含第七/八幕真分支与 5 尾声）——真分支是"去官网看"的理由
  • 惠卿视角的选择点（第三幕后才有）
  • 分享卡自生成、埋点、真实广告网络、口令/深链、多剧本模板
  • 入戏 App 引擎特性（多人房间、实时对局、账号）
明确不做
  • 不登录、无后端、无实时 LLM（scope 明砍）
  • 不改剧本文本——原样裁剪是"产品本体的一刀切片"承诺
  • 不接真实广告网络——只做假素材演示
  • 不做桌面深度适配——消费场景在手机

待办问题（不阻塞 4-spec）

  • 台词（非旁白）配音资产现状——旁白 nar_* 全量现成；台词行音频构建期盘点，缺则只为这 368 步补生成。
  • 结算页与分享文案初稿——本文档已起草，学习者批准后定稿。
  • 微信"轻触解锁音频"具体表现——首屏方案已定，机型差异构建期实测校准。
