# 回山试玩版 — Product Requirements

One line: 把入戏正式剧本《回山》的第一、二幕原样裁成一段手机即点即玩的有声互动试玩，玩到"涂药定格"处切断，把人导去官网——一份"能玩的买量广告"。
Source: `scope.md > The Unique Kernel`（可玩的买量广告）、`scope.md > One line`。

## The Core Journey

完整路径，从头到尾。切片取自 `回山-script_json/script.json` 正本 **seq 1–368**（共 368 步），文本、背景、音乐、旁白音频全部原样，不改一个字。

1. **点开链接**（微信内置浏览器 / 手机浏览器）→ 直接看到第一幕场景（`bg_shop_dusk` 傍晚药铺前堂铺满全屏）+ 居中一枚"轻触 开启剧情"印——这是唯一一次点击门槛（手机浏览器禁止自动出声，必须一次点击解锁音频）。
2. **轻触后**：`bgm_daily` 起，第一句旁白配音出声（"陈记药铺开在山门外的长街上……江明蹲在门口修门槛。"），台词打字机逐字出现，角色台词带头像（`江明.png` / `陈惠卿.png`）。点击屏幕＝当前句立即显示完整 / 跳下一句。
3. **第一幕 · 照常开门**（seq 1–约 180）：修门槛、替老周抓药、喜酒打趣、分半碗饭——约 64 步日常原样保留。
4. **选择 ①**（seq 66，江明的选择）：惠卿问"看什么？"，弹出 4 个选项——"周叔下回还问，你还替我挡？"/"刚才怎么不让我说？"/"没什么。门槛右边你别踩。"/"（不答话）"。**选谁都真实改变接下来的来回对话**（seq 69–88 各不相同），随后汇合。
5. **钩子落下**（S01 后段）：韩策送来复名帖、腰牌与接脉消息——明早卯时启阵、十年一次、旧伤等不了。BGM 切 `bgm_uneasy`。江明答应明早回山见人，但没答应接脉；惠卿读帖、去找剑。
6. **第二幕 · 旧东西**（seq 约 181–368）：储物间翻旧物（`bg_store_night`）、拆青衣侧缝、后院试剑（`bg_courtyard_night`）。
7. **选择 ②**（seq 272，江明的选择）：她缝他捡他那天的旧青衣，4 个选项——"我又没答应接脉。"/"你早就想过我会回去？"/"你说，我这伤真能接好？"/"（不答话）"。同样真实改变当场来回。
8. **切断定格**（seq 368）：试剑第三式震得药架晃 → 药罐旧事（"猫会把碎片收在井台底下？"）→ 她拉过他的手腕替他涂肩伤——最后一句"她继续替他抹开。"画面停住，进入结算页。
9. **结算页（导流）**：定格背景压暗 → 悬念文案 → "你的选择"摘要两行 → "去入戏 App 看结局"按钮（跳 `https://www.enterdrama.cn/`）→ 激励视频广告占位卡 + "重玩一次"。
10. **结局只有两个出口**：跳官网，或清进度重玩。成功＝玩家读完 368 步、做过 2 次选择、点了官网按钮。

## Screens and Layout

一块全屏竖向舞台，无导航、无菜单、无进度条（Source: `scope.md > The Core Loop`"无菜单无加载页"）：

- **舞台层**：背景图 9:16 全屏 cover，场景切换淡入淡出；桌面端居中竖屏画布（手机视图等比放大）。
- **对话层**：底部对话框——宣纸质感底、墨色正文、左侧圆框头像 + 角色名；旁白无头像、字体略灰。台词打字机逐字。
- **选择层**：选择出现时对话框位置换成选项卡组——竖排 4 枚朱砂印章式按钮；点击后收起，继续播对应分支。
- **常驻广告层**：底部细条 banner 广告占位（结算页隐藏）。
- **结算层**：全屏结算页（构成见"结算页"行为节）。
- 无其他页面。移动竖屏优先，微信内置浏览器与手机浏览器可开；桌面可开、居中画布、不深适配。

## Look and Feel

Source: 学习者拍板"古风拟物"；场景美术与头像直接复用《回山》官方资产（写实国风 9:16 空镜，药铺朴素/宗门仙气两种空间气质）。

- **质感**：宣纸底、墨色字、朱砂印章式按钮；细回纹/云纹描边装饰，克制不堆砌。
- **字体**：衬线宋楷系（宋体/楷体优先级回退），标题与正文同族不同字重。
- **配色**：宣纸米白底、墨黑正文、朱砂红点睛（选择按钮/关键印）、淡金做分隔线；整体低饱和，贴《回山》"木色与陶土色"美术口径。
- **动效**：打字机逐字；选择按钮朱砂印"盖下"微动效；背景淡入淡出。不做多余粒子/翻页特效。
- **避免**：现代玻璃拟态、纯黑底白字、Q 版元素、任何不属剧本的插画。

## Features and Behavior

### 有声播放器

- 旁白逐句播 `nar_*.mp3` 配音（切片内音频全量现成）；台词行播角色配音（构建期盘点现成资产，缺的只为这 368 步补生成，不许台词无声——"第一秒就是出声的剧情"是 scope 承诺）。
- 打字机与配音同步开始；点击屏幕＝未完句立即完整、已完成则下一句；音频不打断，仅台词提前。
- BGM 按 music 步切换循环（`bgm_daily` → `bgm_uneasy` → 回 `bgm_daily`）；不播剧本文本外的音效。
- 背景随 background 步淡入淡出切换（本切片 4 张：`bg_shop_dusk` / `bg_shop_night` / `bg_store_night` / `bg_courtyard_night`）。
- 验收：
  - [ ] 轻触后 3 秒内第一句配音出声
  - [ ] 每句旁白/台词出现即有声；点按能跳句不卡死
  - [ ] 4 处背景切换与 music 步切换在正确节点发生

### 玩家选择

- 两个选择点（seq 66 / seq 272）均弹出 4 选项：3 个剧本原文选项 + 1 个"（不答话）"（即剧本超时支，无倒计时——学习者拍板：沉默做成普通选项）。
- 选项原文照抄剧本，不缩写不润色；选择后按钮收起、播对应分支、汇合后继续。
- "你的选择"记录进摘要（结算页用）。
- 验收：
  - [ ] 两个选择点各出 4 枚按钮，选项文案与剧本正本逐字一致
  - [ ] 选 A 与选 B 后接下来的台词确实不同（对照两条路径各走一遍）
  - [ ] 选"（不答话）"走通剧本超时支（seq 67→89 / seq 273→299）

### 结算页（导流）

构成（自上而下）：

1. 定格背景压暗 + 一枚朱砂印"待续"
2. 悬念文案（初稿，学习者评审）：主句 **"天亮之前，他得给个答案。"** 副句 **"可这段对话，停在了药膏擦上去的那一刻。"**
3. **"你的选择"摘要**两行：`第一幕，你替江明说：「……」` / `第二幕，你替江明说：「……」`；若选沉默则显示 `他没答话。`
4. CTA 按钮 **"去入戏 App 看结局"** → 新窗口打开 `https://www.enterdrama.cn/`
5. 激励视频广告占位卡
6. "重玩一次"文字按钮 → 清进度、回第 1 步

- 页面 `document.title` 设为分享标题初稿：**"入戏·回山试玩｜天亮之前，他得选"**（微信分享卡默认取页面标题，POC 不接 JS-SDK）。
- 验收：
  - [ ] 摘要与实际所选逐字一致（含沉默显示"他没答话。"）
  - [ ] CTA 在微信与手机浏览器中都能打开官网
  - [ ] "重玩一次"清空进度、回到轻触首屏

### 广告占位（假素材演示）

Source: `scope.md > The POC Boundary`"结构搭好、占位素材演示，不接真实广告网络"。学习者拍板：做像模像样的假广告图，不做灰卡。

- **底部 banner 位**：一张古风修仙风假广告图（自制假素材，非真实广告网络）+ "广告"角标；播放中常驻。
- **激励视频位**：结算页假广告卡（如"看视频领独家剧情卡"样式）→ 点击演示完整结构：全屏假广告图 → 3 秒倒计时 → 出现关闭 → 返回结算页。
- 验收：
  - [ ] banner 在播放全程可见（结算页除外）、带"广告"角标
  - [ ] 激励视频位可走完"点开→倒计时→关闭→回结算页"全流程

### 进度与重玩

- localStorage 记录当前 seq 路径位置 + 两个选择的结果；中途关页，再次打开**直接恢复到断点台词**（不询问）。
- 无进度记录 → 从轻触首屏开始；结算页"重玩一次" → 清记录从头。
- 验收：
  - [ ] 播到任一处关页重开，接着上一句继续，且已做选择不丢
  - [ ] 清空 localStorage 后从头开始

## States and Boundaries

- **首次使用（音频解锁）**：手机浏览器禁止自动出声，故首屏＝第一幕背景铺满 + 居中"轻触 开启剧情"印，点击后音频起。这是对 scope"无菜单无加载页"的最小调和：无任何菜单信息，只有一次必要点击。（假设，构建时按微信实测校准）
- **断点恢复**：有进度 → 直接跳断点继续；无进度 → 从头。恢复时选择结果一并还原。
- **音频缺失/加载慢**：台词照常打字机推进，配音缺席静默降级，绝不阻塞或白屏。
- **资产加载失败**：背景缺失用暗色底 + 场景名淡字占位，流程不中断。
- **结算页是终点**：只能跳官网或重玩，无"继续阅读"。
- **微信内置浏览器**：可完整游玩；分享卡标题即页面 title；不接微信 JS-SDK。
- **桌面端**：居中竖屏画布可完整走通，不深适配。
- **内容边界**：只播正本 seq 1–368；剧本文字零改动。新增文字仅限：界面 chrome（轻触印、"不答话"选项标签）、结算页文案、分享标题——全部属本 PRD 已列初稿。

## Product Decisions

- **玩家双角色全操纵** — 原版双人对局，H5 单人玩：江明、惠卿的选择都由玩家做（学习者拍板）。本切片两个选择点恰好都是江明的，摘要称"你替江明说"。
- **切断点＝第二幕末"她继续替他抹开。"**（seq 368）— 符合 scope 原则：2 次选择已做、分支后果已尝到、接脉大钩子（韩策送帖）已砸下，情感拍点收在最温柔处突然断掉。
- **开场约 64 步日常原样保留** — 日常铺垫是这剧本的根，黄金三章逻辑靠日常质感立信，不精简（学习者拍板）。
- **超时支做成"（不答话）"普通选项** — 保留剧本超时内容，不给玩家倒计时压力（学习者拍板）。
- **localStorage 断点续玩** — 3 分钟试玩也会被切走，回来接着玩（学习者拍板）。
- **结算页带"你的选择"摘要** — 强化"剧情真的因你而变"（学习者拍板）。
- **假广告做成像样的假图** — 接近真实投放观感（学习者拍板）。
- **视觉＝古风拟物**（宣纸/墨/朱砂，衬线宋楷）（学习者拍板）。
- **官网地址**：`https://www.enterdrama.cn/`（学习者提供）。
- **结算页与分享文案由 agent 起草** — 已列初稿于本文档，学习者评审把关（非学习者原创，待批）。

## What We're Building

试玩切片播放器（seq 1–368 原样数据 + 有声播放 + 打字机）＋ 2 个选择点（含"不答话"）＋ 切断定格 ＋ 结算导流页（悬念文案/选择摘要/官网 CTA/激励视频占位/重玩）＋ 底部 banner 占位 ＋ localStorage 进度 ＋ 古风拟物 UI ＋ 假广告素材 2 张。纯前端静态托管，微信与手机浏览器可玩。

## Deferred From the POC

- **第三幕起的全部剧情**（含第七幕留/走、第八幕接脉两个真分支与 5 份尾声）— POC 只切前两幕；真分支是"去官网看"的理由，不是要搬进 H5 的内容。
- **惠卿视角的选择点** — 第三幕后才有；本切片两处选择都是江明的。
- **分享卡自生成、埋点、真实广告网络、口令导流/深链、多剧本模板化** — scope `Later` 原样顺延。
- **入戏 App 的引擎特性**（多人房间、实时对局、账号）— 完全不沾，scope `Explicitly Cut`。

## Non-Goals

- **不登录、无后端、无实时 LLM** — scope `Explicitly Cut`。
- **不改剧本文本** — 原样裁剪是"产品本体的一刀切片"承诺；只有 PRD 列明的界面/结算文案是新增。
- **不接真实广告网络** — 只做假素材演示。
- **不做桌面深度适配** — 消费场景在手机。

## Possible Later Enhancements

- 第三幕–第八幕逐幕解锁，做成系列试玩。
- 结算页按玩家选择显示不同悬念文案（个人化钩子）。
- 真实广告网络替换占位素材。
- 分享卡带选择结果自生成。

## Open Questions

- **台词（非旁白）配音资产现状** — 旁白 `nar_*` 全量现成；台词行是否有现成音频需构建期盘点，缺则只为这 368 步补生成。**不阻塞 4-spec**，构建期处理。
- **结算页与分享文案初稿** — 本文档已起草，属评审项，学习者批准后即定稿。
- **微信内"轻触解锁音频"的具体表现** — 首屏方案已定，实际机型的自动播放策略差异构建期实测校准。不阻塞 spec。
